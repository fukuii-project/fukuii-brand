Fukuii is a Scala execution client for the wider Ethereum Virtual Machine ecosystem.

It runs any EVM-compatible network from a single binary — Ethereum Classic, Ethereum mainnet, and Sepolia via Engine API V1 through V4. Because it runs on the JVM, its stack aligns with the infrastructure of modern finance.
